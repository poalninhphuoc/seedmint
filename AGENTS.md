# AGENTS.md

seedmint generates realistic, seeded sample data from a pasted schema. Read `docs/architecture.md` first.

- Language: TypeScript. Keep code local-only: never send user schemas to a network service.
- Fake data must be format-valid but not real personal data.
- Ideas, brainstorms and rankings live outside this repo (`../_ideas`). Do not add them here.
- README is multilingual: when changing `README.md`, mention what needs updating in the translated files.
